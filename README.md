# EngineeringChangeMarker（工程变更标记宏）

一个用于 Word 的宏模板（.dotm）。在提交文档时运行它，可以自动标记修改位置并涂色，为每个版本的变更留下清晰的"修改印记"，方便校对与版本比对。

## 功能特性

- **自动标记修改**：运行宏后自动定位文档中的修改内容，并在修改位置留下标记
- **修改内容涂色**：对修改过的文字高亮显示，打开文档即可一眼定位变更
- **支持校对比对**：结合"审阅"视图使用，可对照查看修改前后的内容
- **面向工程变更场景**：适用于图纸说明、技术文件、设计文档等需要严格版本管理的文件

## 安装方法

推荐使用**全局加载项（Word Add-in）**方式安装。这种方式的原理是：宏模板被 Word 全局加载，宏代码对所有文档生效，无需在每份文档里重复导入，一次安装即可长期使用。

### 方式一（推荐）：作为全局加载项安装

1. 下载本仓库中的 `EngineeringChangeMarker.dotm` 文件
2. 将文件复制到 Word 的启动文件夹（STARTUP）：
   - 按 `Win + R` 打开"运行"窗口，输入 `%APPDATA%\Microsoft\Word\STARTUP` 并回车
   - 将 `EngineeringChangeMarker.dotm` 粘贴进该文件夹
   - 若文件夹不存在，可手动创建
3. 完全关闭并重新打开 Word，使模板被自动加载
4. 验证是否加载成功：**文件 → 选项 → 加载项** → 底部"管理"下拉框选 **Word 加载项** → **转到**，列表中应能看到该模板
5. 若宏被禁用：右键该 .dotm 文件 → **属性** → 勾选"解除锁定"，重新打开 Word 即可

安装完成后，模板中的宏对所有 Word 文档（包括普通 .docx）都可用，无需在每份文档中重复设置。

### 方式二：放入用户模板目录

将 .dotm 复制到 Word 的模板目录（`%APPDATA%\Microsoft\Templates`），之后在"文件 → 新建"中基于该模板创建文档。此方式生成的文档自带宏，但只对新建文档生效，已有文档不适用。

### 方式三：单文档临时使用

双击打开 `EngineeringChangeMarker.dotm` 直接编辑使用，或在 VBA 编辑器中（`Alt + F11`）右键导入该模块，仅对当前文档生效。适合临时试用，不建议作为长期方案。

## 使用方法

1. 打开需要标记修改的 Word 文档
2. 按 `Alt + F8` 打开"宏"对话框，选择对应宏并点击"运行"
3. 宏执行完毕后，文档中的修改位置会自动涂色标记
4. 如需比对，可在"审阅"选项卡下对照查看修订记录与批注

> 说明：具体宏名称以实际代码为准，运行前请先确认。

## 注意事项

- 运行前请先另存一份文档副本，避免宏处理结果无法撤销
- 全局加载项方式下宏作用于当前活动文档；若文档本身启用宏（.docm），效果与直接内嵌宏一致
- 本宏基于 VBA 开发，适用于 Windows 版 Microsoft Word

## 兼容性

- 支持：Microsoft Word 2016 / 2019 / Microsoft 365（Windows）
- 注意：Mac 版 Word 对 VBA 支持有限，可能存在兼容性问题
